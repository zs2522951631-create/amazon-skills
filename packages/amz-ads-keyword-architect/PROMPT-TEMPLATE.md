# 可复用 Prompt 模板 · 竞品拓词 → 广告架构

> 配合 `references/01-flow.md` 使用。把 `<>` 占位符填好后发给 Claude，即按八步流程跑。
> 数值类指标 Claude 会用 SIF/Sorftime 取数，缺数据则标「待数据验证」，不编。

---

## 模板正文

```
帮我跑「竞品拓词 → 广告架构」流程（按 amz-ads-keyword-architect 的 references/01-flow.md 的八步）。

【本品锚点】
- 产品：<一句话说明本品是什么>
- 核心 spec：<材质/规格/型号/形态/适用对象>
- 必含属性：<必须命中的属性，逗号分隔>
- 必排属性：<冲突属性/配件/替代品，逗号分隔>
- 自有品牌：<品牌词>　竞品品牌：<竞品品牌词>

【竞品 ASIN】（3-5 个）
<ASIN1, ASIN2, ASIN3, ...>

【站点】<US / CA / UK / DE / FR / IT / ES，可多选，默认 US>

【类目】<具体类目，用于阈值校准；留空则用通用默认阈值，但 skill 会先提示确认>

【数据源】（双选项：给了就读，没给就抓）
- ABA：<粘贴导出 / 无（无则用 SIF/Sorftime 近似）>
- 选品指南针/商机探测器：<粘贴导出 / 无（无则用 SIF/Sorftime 近似）>
- 竞品反查词：<让你用 SIF/Sorftime 抓 / 我自己粘>
- 评论 VOC：<需要 / 不需要；走 Sorftime ProductReviewsQuery，实时采集需确认积分消耗>

【输出要求】
- <分级词表 Excel / 投放主题簇 / 广告 campaign 架构图，勾选要哪些>
- 报告形态：<单文件 HTML / Markdown / Excel>

【执行约束】
1. 先回显本品锚点 + 竞品 ASIN 串让我确认，再开抓数据。
2. 词频只作机会维，不当相关性；相关性按反查 ASIN 同类占比判。
3. 数值类指标必须工具取数，缺数据标「待数据验证」，禁止编造。
4. 否词从头沉淀进否词池。
5. 广告分级按「相关性×搜索量×竞争/CPC×趋势」四维，不只看竞争度。
```

---

## 配套提醒（给执行者）

- **开跑前必做**：回显竞品 ASIN 串原文让用户确认，防止 ASIN 录入串行/错位。
- **VOC 实时采集**前确认积分消耗。
- **分类/评分**：本 skill 自包含，走 `references/03-classification.md`（属性 7 类）和 `references/06-tools-data.md`（评分骨架），不依赖旧 skill。
- **缺口**：ABA/选品指南针无直接 MCP，需用户粘导出或用 SIF/Sorftime 近似。
