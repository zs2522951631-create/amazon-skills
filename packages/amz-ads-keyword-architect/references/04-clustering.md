# 语义聚类成投放主题簇（Step 6）

> 广告架构的单元是**「ad group 主题簇」**，不是单词根。聚类是从「词根」到「广告分级」之间缺失的关键一步。

---

## 聚类原则

### 聚类单元是 ad group 主题簇，不是单词根

- 用 **embedding 聚类 / LLM 归主题**，把同意图、同属性维度的词归一个 **ad group 主题**（不是按词根前缀机械分组）。
- 每个主题簇对应一个 ad group 投放单元；簇内词共享同一投放逻辑（匹配方式/出价/攻守策略）。
- 聚类粒度的目标：**簇内词语义高度一致，跨簇词意图显著不同**。

---

## 簇数量上限

| 产品类型 | 最大 ad group 主题簇数 |
|---|---|
| 标品（如 yoga mat、earbuds、cordless drill 等标准化品类）| ≤ **15** 个 |
| 非标品（如运动相机、婴儿车、复杂配件等多变体/多场景品类）| ≤ **30** 个 |

**超出上限的处理规则**：按「相关性 × 需求」排序，合并低优簇（相关性低且需求低的簇优先合并入最接近的上位簇），直到总数 ≤ 上限。

---

## `coverage_ratio` 对聚类粒度的决策影响

`coverage_ratio`（来自 SIF `market_get_keyword_root_trend`）量化词根需求集中 vs 分散：

| `coverage_ratio` | 含义 | 聚类策略 |
|---|---|---|
| > 0.8 | 需求集中在精确词 | 粒度可粗，重点深挖核心词簇；长尾簇优先级低 |
| 0.4–0.8 | 需求适度分散 | 平衡精确词簇 + 长尾簇 |
| < 0.4 | 需求高度分散在长尾 | **须系统性铺长尾**；非标品适当扩大簇数量上限，增加长尾主题簇覆盖 |

---

## 每个主题簇的必填标注

每个簇输出时须标注以下所有维度（任何一项不能为空）：

| 字段 | 说明 |
|---|---|
| 主题簇名称 | 一句话描述该簇投放意图（如「人体工学高支撑泡沫垫」）|
| 主属性维度 | 对应 7 类分类的哪个维度（属性/场景痛点/人群/长尾组合等）|
| 相关性档 | 高 / 中 / 低 |
| 需求档 | 高 / 中 / 低 |
| 趋势 | 上升 / 平稳 / 衰退 / 季节性（+ 峰值月份）|
| 跨 ASIN 覆盖率 | 该簇核心属性在 N 个竞品 Listing 中出现的比例 |
| `coverage_ratio` | SIF 词根 `coverage_ratio` 值（用于判断长尾铺设必要性）|
| 词数 | 该簇包含的词根数量 |

---

## 输出格式（对接脚本）

聚类结果输出对接脚本的 `--clusters-csv` 参数，CSV 列定义：

| 列名 | 类型 | 说明 |
|---|---|---|
| `主题簇` | string | 簇名称 |
| `主属性维度` | string | 对应 7 类分类维度 |
| `相关性` | string | 高 / 中 / 低 |
| `需求` | string | 高 / 中 / 低 |
| `词数` | int | 该簇词根数量 |
| `趋势` | string | 上升 / 平稳 / 衰退 / 季节性 |
| `跨ASIN覆盖率` | float | 0–1（小数）|
| `coverage_ratio` | float | SIF 词根 coverage_ratio |

---

## 聚类流程

1. **预处理**：以 Step 5 输出的分类词表为输入，排除否词池词汇不进聚类。
2. **Embedding 生成**：对每个词根（含 n-gram）生成向量表示。
3. **LLM 归主题**：结合向量相似度 + LLM 语义理解，将词根归入主题簇（同意图、同属性维度）。
4. **数量检查**：若簇数量超上限 → 合并低优簇。
5. **标注补全**：对每个簇补全必填标注（不能有空字段）。
6. **覆盖率计算**：用 SIF `ops_get_listing_keyword_distribution` 辅助计算跨 ASIN 覆盖率。
7. **输出 `--clusters-csv`**：交 Step 7 广告架构使用。

---

## 常见易错点

- **词根级聚类**（每词一簇）：导致簇数量爆炸，严重超上限。
- **忽略 `coverage_ratio`**：长尾散在时未增设长尾簇，广告覆盖缺口大。
- **跨品类词混入簇**：低相关词未提前过滤（应在 Step 4 打低相关 → Step 5 否词）。
- **簇标注有空字段**：违反 CHECKPOINT 2（广告分级四维须齐全）。
