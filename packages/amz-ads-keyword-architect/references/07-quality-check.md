# 交付前质量自检清单

> 三个 CHECKPOINT 是强制停止点（STOP），不满足则不得继续。

---

## CHECKPOINT 0（Step 0 完成后）

**触发时机**：Step 0 锚点建立完毕，**抓取任何数据之前**。

- [ ] 本品锚点齐全：产品说明 / 核心 spec / 必含属性 / 必排属性 / 否词种子池已初始化。
- [ ] 竞品 ASIN ≥ 3 个，且已**原文回显**竞品 ASIN 串等待用户确认（防 ASIN 串行/错位）。
- [ ] 竞品 ASIN 同类校验通过：类目/形态一致，不一致的已提示用户确认后排除。
- [ ] 类目门已过：用户已确认使用通用默认阈值，**或**已提供具体类目并同意校准。

> ⚠️ CHECKPOINT 0 不通过，禁止开始 Step 1 数据采集。

---

## CHECKPOINT 1（Step 4 完成后，分类/评分结束）

**触发时机**：双维打分 + 属性 7 类分类完成后，**Step 6 聚类之前**。

- [ ] **相关性未用词频/搜索量代理**：抽样 5–10 行，检查相关性判断依据是「反查 ASIN 同类占比 / 语义」，而非词频排名或 ABA 搜索量（高频词 ≠ 高相关）。
- [ ] **属性分类备注不空**：抽样 5–10 行，检查「关键词属性 | 备注」两列均已填写，备注不得为空（见 `03-classification.md` 备注强制规则）。
- [ ] top3_click_share / top3_conversion_share 仅作为竞争信号记录，**未被用于判断相关性**。
- [ ] 否词候选在 CHECKPOINT 1 时已有初始记录（Step 0–4 沉淀）。

> ⚠️ CHECKPOINT 1 不通过，禁止开始 Step 6 聚类。

---

## CHECKPOINT 2（Step 8 输出交付前）

**触发时机**：所有步骤完成，**输出 Excel / HTML / Markdown 之前**。

- [ ] **否词池非空**：否词候选表有内容（至少来自必排属性种子或低相关词）。
- [ ] **广告分级四维齐全**：每个 ad group/簇均标注了相关性 / 搜索量 / 竞争/CPC / 趋势，不能只有竞争度单维。
- [ ] **数值无编造**：所有数值类指标（词频/SFR/CPC/份额/排名）来自 SIF/Sorftime 取数；缺数据的列标「待数据验证」，不编造。
- [ ] **Excel 含应有 Sheet**（按脚本实际产出核对，分三类，别与脚本对不上）：
  - **恒定产出（7，无条件）**：拓词总表 / P0-P1优先词 / Listing埋词建议 / PPC投放建议 / 否词候选 / 来源汇总 / 执行说明
  - **条件产出（按入参才出现）**：主题簇（传 `--clusters-csv`，Step 6 聚类）/ 广告架构（传 `--architecture-csv`，Step 7 决策矩阵）/ ASIN画像（传 `--asin-summary`）
  - [ ] 否词候选**非空**（脚本在其为空时打 `[warn]` 告警；若告警则补 `--conflict-terms` 或确认确无否词）
  - [ ] 主题簇 + 广告架构**已生成**：完整广告架构交付**必须**传 `--clusters-csv` / `--architecture-csv`，否则这两表不出现 = 交付不完整
- [ ] **下游 2 Sheet 已生成且未被编造填充**（除非 `--no-downstream`）：
  - [ ] VOC词库（口语词→标准搜索表达映射；证据片段为 Review/QA 原文或留「待填」，禁止编造）
  - [ ] 收录排名追踪（P0/P1/P2 词台账；收录/排名/ACOS/订单等指标列保持「待检测/待数据验证」直至工具取数回填）

> ⚠️ CHECKPOINT 2 不通过，禁止输出最终交付物。任何「待数据验证」的字段须明确标注，不得留空白或编造数值。下游 Sheet 是**待填脚手架**——交付时保持占位符即合规，回填时只能用工具实测值。
