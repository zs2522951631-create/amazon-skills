# 关键词 7 类属性分类

属性分类只看语义,不看搜索量、转化率、是否好卖、是否当前投放、主观精准度。搜索量等指标只能用于后续运营优先级评分。

## 优先级链

分类时只能选择**一个**最高优先级结果:

```
品牌词 > 否词 > 人群词 > 场景痛点词 > 属性词 > 核心大词 > 长尾组合词
```

注意:**竞品品牌词**归为品牌词,但需要在备注中标记"竞品",并在广告策略中标记"谨慎/否定"。

## 7 类详细规则与跨类目示例

### 1. 核心大词

**定义**:产品本质的词,搜索意图宽泛,通常不包含具体参数或限定。

**判断**:
- 只是产品本体或类目指代
- 无属性、场景、人群、痛点、品牌限定
- 如果数据表有明确搜索排名,可优先把排名靠前的产品本体词作为核心大词候选

**Listing 用途**:
- Title 前段尽可能早、完整、连续出现
- 做自然排名和广告排名追踪

**备注规则**:填 `-`

**跨类目示例**:
- 运动类:`yoga mat`
- 3C 类:`wireless earbuds`、`bluetooth earbuds`
- 工具类:`cordless drill`、`power drill`
- 服饰类:`running shoes`
- 美妆类:`face cream`、`moisturizer`
- 母婴类:`baby stroller`、`stroller`
- 食品类:`protein powder`
- 办公类:`standing desk`

### 2. 品牌词

**定义**:明确包含品牌名、商标名、系列名的词。

**规则**:
- 只判断是否品牌词,不在分类阶段判断是否侵权
- 竞品品牌词单独管理,广告使用需标注"谨慎"
- 涉及商标风险时进一步标注

**备注规则**:填品牌名,保留原词形(如 "Lululemon"、"Nike"、"Anker"、"DeWalt")

### 3. 属性词

**定义**:描述产品材质、技术参数、规格、颜色、款式、结构、功能形态、配件、承重、尺寸等。

**判断**:
- 如果关键词可拆为"核心产品词 + 单一属性片段",判为属性词
- 即使词数很多,只要只有一个属性维度,也不得判为长尾组合词

**用途**:
- Bullets 首句、参数段、A+ 对比表
- SP 精准或词组广告测试

**备注规则**:填具体属性片段(从关键词中删除核心产品词后剩余的连续片段)

**跨类目示例**:

| 关键词 | 备注 | 类目 |
|--------|------|------|
| thick yoga mat | Thick | 运动 |
| extra thick non slip yoga mat(只 1 个属性时仍是属性词) | Extra thick non slip | 运动 |
| noise cancelling earbuds | noise cancelling | 3C |
| 20v cordless drill | 20v | 工具 |
| 1/2 inch chuck drill | 1/2 inch chuck | 工具 |
| waterproof running shoes | waterproof | 服饰 |
| retinol face cream | retinol | 美妆 |
| compact baby stroller | compact | 母婴 |
| organic protein powder | organic | 食品 |
| adjustable standing desk | adjustable | 办公 |

### 4. 场景痛点词

**定义**:描述用户使用场景、问题、需求或痛点的词。即使词中没有产品名,只要核心是解决问题,也可以判为场景痛点词。

**常见类型**:
- 场景:`home gym`、`apartment`、`office`、`travel`、`pool`、`camping`、`small space`
- 痛点:`weight loss`、`bad knees`、`lymphatic drainage`、`non slip`、`quiet`、`easy install`

**用途**:
- Title 后半段增加点击相关性
- Bullets 痛点阐述段
- A+ 场景模块、QA/FAQ、站外内容

**备注规则**:填对应场景或痛点表达

**跨类目示例**:

| 关键词 | 备注 | 类目 |
|--------|------|------|
| yoga mat for bad knees | for bad knees | 运动(健康痛点) |
| earbuds for small ears | for small ears | 3C(身体适配) |
| drill for tight spaces | for tight spaces | 工具(空间场景) |
| shoes for flat feet | for flat feet | 服饰(身体痛点) |
| cream for sensitive skin | for sensitive skin | 美妆(肤质痛点) |
| stroller for travel | for travel | 母婴(场景) |
| protein powder for weight loss | for weight loss | 食品(目标场景) |
| desk for home office | for home office | 办公(场景) |

### 5. 人群词

**定义**:明确指出给某一类人使用或购买的词。

**判断**:
- 年龄、性别、职业、身份、成长阶段、特殊人群
- 如果词语语义上指代人类,并以年龄或成长阶段区分(`kids`、`teen`、`seniors`),**必须优先判为人群词**(因为人群词优先级高于属性和场景痛点)

**备注规则**:填对应人群表达,必要时可映射为 Child / Teen / Senior / Adult / Women / Men / Beginner / Professional

**跨类目示例**:

| 关键词 | 备注 | 类目 |
|--------|------|------|
| yoga mat for women | for women(性别) | 运动 |
| earbuds for kids | for kids(年龄段) | 3C |
| drill for beginners | for beginners(技能阶段) | 工具 |
| shoes for plus size | for plus size(身材) | 服饰 |
| cream for women over 50 | for women over 50(年龄+性别) | 美妆 |
| stroller for newborn | for newborn(成长阶段) | 母婴 |
| protein for athletes | for athletes(职业身份) | 食品 |
| desk for professionals | for professionals(职业) | 办公 |

### 6. 长尾组合词

**定义**:**不是词数多**,而是至少包含**两个及以上不同语义维度**。

**允许判为长尾组合词的组合**:
- 人群 + 属性
- 场景痛点 + 属性
- 场景痛点 + 人群
- 场景痛点 + 人群 + 属性

**禁止误判**:
- "核心产品词 + 单一属性片段"即使超过 3 个词,也仍是属性词
- 不能用词数、搜索量、主观精准度来判长尾组合词

**备注规则**:填 `-`

**跨类目示例**:

| 关键词 | 维度组合 | 类目 |
|--------|----------|------|
| extra thick yoga mat for bad knees | 属性 + 场景痛点 | 运动 |
| noise cancelling earbuds for sleeping | 属性 + 场景 | 3C |
| lightweight cordless drill for women | 属性 + 人群 | 工具 |
| wide running shoes for flat feet | 属性 + 痛点 | 服饰 |
| retinol face cream for sensitive skin | 属性 + 痛点 | 美妆 |
| lightweight stroller for travel | 属性 + 场景 | 母婴 |
| organic protein powder for women over 50 | 属性 + 人群 | 食品 |
| adjustable standing desk for tall people | 属性 + 人群 | 办公 |

### 7. 否词

**定义**:
- 与产品客观属性直接冲突的词
- 搜索意图指向完全不同产品或类目的词
- 广告中高点击无转化且相关性弱的词
- 季节过期、节日过期、使用场景不再匹配的词

**类目化属性冲突示例**:

| 产品属性 | 否词候选 |
|----------|----------|
| Corded Vacuum | Cordless |
| Fixed 家具 | Foldable |
| Manual 工具 | Electric |
| Matte 美妆 | Glossy |
| Plus Size 服饰 | Petite |
| Sugar-Free 食品 | 含糖类相关词 |
| Indoor 用品 | Outdoor |
| Wired 3C | Wireless |

**季节/节日过期词**:情人节、母亲节、圣诞节、黑五等相关词在节后要复盘是否继续保留。

**备注规则**:填 `-`

## 备注列强制规则

输出关键词属性分类表时,必须新增或填写 `关键词属性 | 备注` 两列。

| 关键词属性 | 备注填什么 |
|------------|------------|
| 核心大词 | `-` |
| 品牌词 | 品牌名(保留原词形) |
| 属性词 | 从关键词中删除核心产品短语后,剩余连续片段 |
| 场景痛点词 | 对应场景或痛点表达 |
| 人群词 | 对应人群表达 |
| 长尾组合词 | `-` |
| 否词 | `-` |

**通用约束**:
- 每一行备注不能为空
- 备注中的英文必须保留**原词形、原拼写、原大小写、原空格与标点**,不做同义替换或语法润色
- 禁止删除、修改、覆盖原表已有列;只能新增分析列
